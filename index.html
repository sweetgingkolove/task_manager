Google Drive Sync

Save your intentions privately in your Google Drive to sync seamlessly across your phone, tablet, and computer. Only your tasks data file is accessed.

Quick Setup (Free & 2 mins):
  1. Open Google Cloud Console and create a project (e.g. Tasks).
  2. Enable Google Drive API under APIs & Services → Library.
  3. Configure OAuth Consent Screen (User Type: External). Add your Google email as a test user.
  4. Go to Credentials → Create Credentials → OAuth client ID (Web application).
  5. Under Authorized JavaScript origins, add:
    http://localhost:8000 and/or https://sweetgingkolove.github.io
  6. Copy the Client ID, paste it above, and click Save.
